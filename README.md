# ربات تکالیف مجموعه رشد (بله) — فاز ۱ و ۲

## راه‌اندازی سریع
1. در بله با `@botfather` یک ربات بساز و توکن را بگیر.
2. `cp .env.example .env` و `BALE_TOKEN` را پر کن.
3. `pip install -r requirements.txt`
4. تست اتصال: `python -m roshd_bot.main --check`
5. اجرا: `python -m roshd_bot.main` ، سپس در ربات `/myid` بزن، عدد را در `ADMIN_IDS` بگذار و ربات را دوباره اجرا کن.
6. تست خودکار: `python -m unittest tests.test_all -v`

## ساختار
- `bale.py` کلاینت API بله · `db.py` دیتابیس SQLite · `rules.py` قوانین تاخیر/نشان (خالص و تست‌شده)
- `bot.py` گفتگوها · `timeutil.py` تاریخ شمسی و ارقام فارسی · `main.py` حلقهٔ دریافت پیام

## قوانین
- به‌موقع = تا «مهلت + ۲۰ دقیقه»؛ تاخیر از خود مهلت محاسبه می‌شود.
- زمان ارسال = زمان آخرین فایلی که دانش‌آموز فرستاده (نه زمان زدن «ثبت نهایی»).
- هر ۶ تکلیف اصلیِ به‌موقعِ پشت‌سرهم = یک نشان تعهد؛ تاخیر یا ارسال‌نشدن شمارش را صفر می‌کند؛ عذر موجه و تکالیف اختیاری/امتیازی خنثی‌اند.
- تکالیفی که قبل از عضویت دانش‌آموز ساخته شده‌اند در آمار او نمی‌آیند.

## فاز ۲
- ارسال بسته می‌شود ۲۴ ساعت بعد از مهلت. «درخواست ارسال مجدد» مدیر یک پنجرهٔ ۲۴ ساعته از لحظهٔ درخواست باز می‌کند و وضعیت زمانی را عوض نمی‌کند.
- پنل هر تکلیف (📋 تکالیف): بررسی تک‌تک دانش‌آموزان (دیدن پاسخ، بازخورد، ارسال مجدد، تمدید فردی، عذر موجه)، تمدید برای همه، ویرایش، دانلود zip، بایگانی.
- 📢 پیام همگانی و 📊 خروجی اکسل (سه شیت: خلاصه، ماتریس، جزئیات).
- لوگو: `roshd_bot/assets/logo.png` (برای پیام خوش‌آمد و اکسل). عکس پروفایل ربات: `bot_avatar_512.png` را در BotFather بگذار.

## فاز ۳
- پنل وب فقط‌خواندنی با رمز ثابت (`PANEL_PASSWORD`)؛ دیدن آمار، تکالیف، پاسخ‌های عکس‌دار و دانلود اکسل.
- زمان ارسال = آخرین ارسال دانش‌آموز (به‌جز ارسال مجددِ درخواستیِ مدیر که تاخیر حساب نمی‌شود).
- نشان تعهد و ۱۰ امتیاز برای هر ۵ ارسال متوالیِ به‌موقع.
- راهنمای اجرای لوکال: `docs/راهنمای-نصب-لوکال.md`
