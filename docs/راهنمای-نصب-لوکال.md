# راهنمای اجرای ربات روی کامپیوتر خودت

## ۱) پیش‌نیازها

| مورد | توضیح |
|---|---|
| Python نسخهٔ ۳٫۱۰ یا بالاتر | از python.org نصب کن؛ در ویندوز تیک **Add Python to PATH** را بزن |
| توکن ربات | در بله با «BotFather» گفتگو کن: `/newbot` ← نام و نام کاربری ← توکن را کپی کن |
| عکس پروفایل | در همان BotFather عکس `bot_avatar_512.png` را برای ربات بگذار |

## ۲) راه‌اندازی (یک‌بار)

1. پوشهٔ پروژه را از zip بیرون بیاور (مثلاً `C:\roshd_bot`).
2. فایل `.env.example` را کپی کن و اسمش را `.env` بگذار، بعد با Notepad باز کن:
   - `BALE_TOKEN` ← توکن
   - `PANEL_PASSWORD` ← رمز پنل وب (حداقل ۸ نویسه)
   - `ADMIN_IDS` فعلاً خالی بماند
3. در پوشه، ترمینال را باز کن (ویندوز: در نوار آدرس `cmd` بنویس و Enter) و تست اتصال:

```bash
python -m venv .venv
.venv\Scripts\activate          # لینوکس/مک: source .venv/bin/activate
pip install -r requirements.txt
python -m roshd_bot.main --check
```

اگر نام ربات چاپ شد، اتصال و توکن درست است.

4. اجرا با `start.bat` (لینوکس/مک: `./start.sh`). این اسکریپت اگر برنامه متوقف شود، ۱۰ ثانیه بعد خودش دوباره اجرایش می‌کند.
5. در بله به ربات خودت پیام `/myid` بده، عددی که می‌دهد را در `.env` جلوی `ADMIN_IDS=` بگذار و اسکریپت را ببند و دوباره اجرا کن. حالا منوی مدیر را می‌بینی.

> ⚠️ همیشه **فقط یک نمونه** از ربات با یک توکن اجرا شود. اگر همزمان روی دو کامپیوتر اجرا شود، پیام‌ها بین‌شان پخش می‌شود و رفتار عجیب می‌بیند.

## ۳) چک‌لیست تست دستی (۱۰ دقیقه)

1. «🗂 گروه‌ها» ← گروه تست بساز.
2. «👥 دانش‌آموزان» ← یک نفر با نام خودت اضافه کن، کد را بگیر.
3. `/asstudent` را بزن (نمای دانش‌آموز) ← ثبت‌نام با گروه، نام و کد.
4. با `/start` به نمای مدیر برگرد ← «➕ تکلیف جدید» با مهلت چند دقیقهٔ بعد و یک عکس ضمیمه.
5. دوباره `/asstudent` ← تکلیف را ببین ← چند عکس بفرست ← «ثبت نهایی».
6. صبر کن تا مهلت + ۲۰ دقیقه بگذرد، یک تکلیف دیگر را با تاخیر بفرست و میزان تاخیر را ببین.
7. در مدیر: «📋 تکالیف» ← بررسی دانش‌آموز ← بازخورد، ارسال مجدد، تمدید.
8. «📊 خروجی اکسل» و «📥 دانلود پاسخ‌ها» را امتحان کن (این‌ها آپلود فایل‌اند؛ اگر خطا داد خروجی ترمینال را برایم بفرست).
9. پنل وب: مرورگر ← `http://localhost:8080` ← با رمز وارد شو.
10. ربات را ببند و دوباره باز کن؛ داده‌ها باید سر جایشان باشند.

## ۴) پنل وب

- آدرس روی همین کامپیوتر: `http://localhost:8080`
- برای دیدن از گوشی (فقط داخل همان وای‌فای): `PANEL_HOST=0.0.0.0` بگذار و با IP کامپیوتر باز کن، مثلاً `http://192.168.1.20:8080`. ویندوز ممکن است اجازهٔ فایروال بخواهد. روی اینترنت عمومی باز نکن؛ ورود فقط رمز ساده است و HTTPS ندارد.
- پنل فقط‌خواندنی است: هیچ دکمهٔ تغییر یا حذفی ندارد.

## ۵) روشن و پایدار نگه داشتن

| مورد | کار لازم |
|---|---|
| خواب کامپیوتر | تنظیمات Power ← Sleep را روی Never بگذار؛ ربات وقتی کامپیوتر خاموش یا خواب باشد جواب نمی‌دهد |
| بعد از ریستارت | ویندوز: Task Scheduler ← Create Basic Task ← «When I log on» ← اجرای `start.bat` |
| اینترنت | اگر قطع شود ربات خودش دوباره تلاش می‌کند |
| ساعت سیستم | باید درست باشد، چون مهلت‌ها با آن سنجیده می‌شود (ساعت پیام از خود بله خوانده می‌شود، ولی محاسبهٔ مهلت با ساعت سیستم است) |

## ۶) بکاپ

همهٔ اطلاعات (دیتابیس و عکس‌های پاسخ) داخل پوشهٔ `data` است. بکاپ دستی: `backup.bat` (لینوکس: `./backup.sh`). بکاپ خودکار روزانه: در Task Scheduler یک کار «Daily» برای `backup.bat` بساز و گاهی پوشهٔ `backups` را روی فلش یا فضای ابری کپی کن.

## ۷) عیب‌یابی

| نشانه | علت محتمل و راه‌حل |
|---|---|
| `--check` خطا می‌دهد (`ConnectError`) | اول `python -m roshd_bot.main --diag` را اجرا کن؛ خودش می‌گوید مستقیم، با پروکسی سیستم یا با پروکسی دستی وصل می‌شود و توصیه می‌کند. ربات پیش‌فرض پروکسی/فیلترشکن سیستم را نادیده می‌گیرد (`USE_SYSTEM_PROXY=0`) |
| `--check` خطای `401/Unauthorized` می‌دهد | توکن اشتباه است |
| `Errno 10048` / پورت ۸۰۸۰ اشغال | یا نمونهٔ دیگری از ربات هنوز در پنجرهٔ دیگری باز است (آن را ببند)، یا برنامهٔ دیگری پورت را گرفته؛ `PANEL_PORT=8090` بگذار. ربات حالا بدون پنل هم بالا می‌آید |
| پیام «ANOTHER INSTANCE …» | ربات قبلاً اجرا شده؛ پنجرهٔ قبلی را ببند. اجرای دو نمونه ممنوع است |
| ربات جواب نمی‌دهد | نمونهٔ دوم در حال اجراست یا برنامه بسته شده |
| توکن را جایی منتشر کردم | همان لحظه در BotFather توکن را بازسازی (revoke) کن و `.env` را به‌روز کن |
| ارسال zip یا اکسل خطا می‌دهد | حجم زیاد یا مشکل آپلود؛ فایل داخل `data\exports` ساخته شده است |
| پنل باز نمی‌شود | پورت ۸۰۸۰ اشغال است؛ `PANEL_PORT=8090` بگذار |
| ساعت مهلت‌ها ۱ ساعت اختلاف دارد | منطقهٔ زمانی ویندوز را روی Tehran بگذار |

## ۸) انتقال بعدی به سرور

کافی است پوشهٔ پروژه (با `.env` و `data`) را روی سرور کپی کنی و همان `start.sh` را اجرا کنی؛ هیچ تنظیم دیگری لازم نیست.
